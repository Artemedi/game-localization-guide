# Манифест репозитория

**Русский** · [English](MANIFEST.en.md)

Что, где и в каком виде хранится в этом репозитории и его релизах. Новая игра, новая страница или новый релиз оформляются по этим правилам.

## 1. Что здесь есть и чего нет

| Здесь | Не здесь |
|---|---|
| Руководство: механика, движки, инструменты, конвейер | Рабочий репозиторий перевода игры (`<game>-ru`): исходники перевода, скрипты, логи прогонов |
| Страница по каждой разобранной игре | Ресурсы игры, оригинальные контейнеры, извлечённые файлы |
| Готовые архивы перевода — **только в [Releases](https://github.com/Artemedi/game-localization-guide/releases)** | Архивы, DLL и прочие бинарные файлы в Git |
| | Ключи API, логи с ключами, личные пути пользователя |

## 2. Структура

```
README.md / README.en.md          точка входа: шаги, список игр, правила
MANIFEST.md / MANIFEST.en.md      этот документ
LICENSE                           CC BY 4.0 (только тексты руководства)
docs/<lang>/                      ru и en, одинаковые наборы файлов
  overview.md                     общая механика, шкала M0–M5
  pipeline.md                     канонический формат, проверки, LLM, проверка в игре
  tools.md                        инструменты по движкам: ✔ применялось / · справочно
  engines/README.md               как определить движок
  engines/<engine>.md             механика движка; пометка [проверено: <игра>] или [обзор]
  examples/<game>-<engine>.md     страница игры (раздел 3)
```

- Каждый документ существует в двух языках с одинаковым именем: `docs/ru/X.md` ↔ `docs/en/X.md`. Изменение одного — изменение обоих в том же коммите.
- `<game>` — короткий slug в нижнем регистре без пробелов (`wyldheart`, `bookoftravels`), `<engine>` — `ue5`, `unity`, `godot`…
- Пометки: **[проверено]** — механизм подтверждён в игре в рамках руководства (указать, на какой игре); **[обзор]** — общеизвестные сведения, не проверялись.

## 3. Страница игры: `docs/<lang>/examples/<game>-<engine>.md`

Обязательные разделы (порядок сохраняется):

0. **Шапка**: ссылки на оглавление и на страницу движка; одна фраза — каких языков нет и как добавлен русский.
   Блок «**Готовый перевод:**» — ссылка на релиз, платформы установщика, качество перевода, версия игры (Steam buildid).
1. **Разведка** — таблица «Что | Значение | Как установлено»: движок и версия, рантайм, контейнеры, где лежит текст, есть ли выбор языка.
2. **Эксперименты** — таблица «Запуск | Что изменено | Результат» с кодами M0–M5; затем выводы, которые стоили больше всего времени.
3. **Итоговый мод** — дерево файлов, которые добавляются в каталог игры, и что каждый делает.
4. **Перевод** — объём, способ (вручную / LLM, модель), что осталось английским и почему, правки по скриншотам.
5. **Проверка без риска для установки** — staging, обёртка запуска, наблюдение, сверка хешей.
6. **Известные ограничения** — то, что не работает или не проверено.

Факты — только подтверждённые запуском или файлами; вывод из кода и гипотезы так и помечаются. Отсутствие строки в логе не доказательство.
Когда игра подтверждает механизм движка, обновить `engines/<engine>.md` (пометка `[проверено: <игра>]`) и `tools.md` (✔), добавить игру в таблицы `README.md`/`README.en.md`.

## 4. Релизы перевода

| Поле | Формат | Пример |
|---|---|---|
| Тег | `<game>-ru-v<semver>` | `bookoftravels-ru-v0.1.0` |
| Заголовок | `<Игра> — русский перевод <версия>` | `Book of Travels — русский перевод 0.1.0` |
| Тип | pre-release, пока перевод машинный без вычитки | |
| Вложение | один архив `<Game>-RU-<версия>.zip` | `BookOfTravels-RU-0.1.0.zip` |

Версия — версия перевода (semver): patch — правки текста, minor — новые области текста или механизмы, major — несовместимая смена способа установки. Версия игры (buildid) указывается в README архива и в описании релиза.

### Состав архива

```
<Game>-RU-<версия>/
  README.txt            RU, затем EN: что внутри, установка, включение, удаление, важно
  install.sh            Linux / Steam Deck  (install.bat + install.ps1 — если Windows поддержана)
  uninstall.sh          (uninstall.bat + uninstall.ps1)
  files/                ровно то, что копируется в каталог игры, в тех же относительных путях
  checksums.sha256      sha256 файлов из files/; установщик сверяет их перед копированием
  THIRD_PARTY.txt       если внутри чужие компоненты (загрузчик модов, шрифт): автор, версия, лицензия, источник
  licenses/             полные тексты этих лицензий
```

Требования к установщику:
- только **добавляет** файлы; оригинальные файлы игры не перезаписывает и не удаляет;
- находит игру через Steam (`libraryfolders.vdf`) или принимает путь аргументом; проверяет, что это та игра;
- записывает список добавленных файлов; `uninstall` удаляет только их и только пустые после этого каталоги;
- повторный запуск безопасен (обновляет свои файлы);
- ничего не скачивает и не ставит другого ПО;
- то, что нельзя сделать безопасно скриптом (например, параметры запуска Steam), выводит инструкцией.

Сборка архива — скриптом из репозитория игры (`tools/build_dist.sh` или аналог), воспроизводимо из закоммиченных исходников.

### Описание релиза (двуязычное)

1. Одна строка: неофициальная локализация `<Игра>` (Steam, buildid N).
2. **Установка / Install** по платформам; ручной вариант.
3. **Включение / Enable** — как выбрать язык или включить мод.
4. Что меняется в каталоге игры и как удалить.
5. **Состояние / Status**: что переведено (числа), качество перевода, известные проблемы, **на чём проверено и на чём нет**.
6. «Не связано с разработчиками игры. / Not affiliated with the game's developers.»
7. SHA-256 архива.

### Чек-лист перед публикацией

- [ ] архив собран скриптом из закоммиченного состояния; `checksums.sha256` сходится;
- [ ] установщик и деинсталлятор проверены на тестовом каталоге (не на установке Steam);
- [ ] прогон в игре с установленным архивом: перевод виден, оригиналы не изменились (сверка хешей);
- [ ] лицензии сторонних компонентов приложены;
- [ ] страница игры (ru/en) и `README` обновлены, ссылка на релиз — на тег;
- [ ] описание релиза честно говорит, что не проверено.
