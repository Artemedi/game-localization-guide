# Game Localization Guide

**Русский** · [English](README.en.md)

Практическое руководство по добавлению новой локализации (например, русской) в игры, где её нет, — **без изменения оригинальных файлов игры**.

Здесь нет готовых переводов и игровых ресурсов: только описание механики, структуры файлов, инструментов и порядка работы, проверенного на реальной игре.

## Для кого

- Для тех, кто делает фанатский перевод и хочет понять, *где* игра хранит текст и *как* подложить свой.
- Для тех, кто уже переводит и хочет воспроизводимый процесс: извлечение → перевод → проверка → сборка → проверка в игре.

## Главные правила

1. **Оригиналы не трогаем.** Перевод — отдельный файл-«мод», который игра загружает поверх своих. Удалил файл — игра снова оригинальная.
2. **Сначала доказать, потом переводить.** Одна тестовая строка в игре важнее тысячи переведённых строк, которые игра не читает.
3. **Одна переменная за эксперимент.** Если что-то не сработало, должно быть понятно, что именно.
4. **Проверять автоматически то, что ломает игру:** плейсхолдеры `{0}`, теги `<b>…</>`, служебная разметка, переносы строк.
5. **Финальная проверка — только на экране.** Отсутствие строки в логе не доказывает, что игра её не загрузила.
