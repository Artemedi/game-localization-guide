# Unreal Engine 4 / 5 **[проверено]**

[← Движки](README.md) · Пример: [Wyldheart, UE 5.7](../examples/wyldheart-ue5.md)

## Где живёт текст

```
<Project>/Content/Paks/
  <Project>-Windows.pak            ← PAK: ini, .locres/.locmeta, шрифты .ufont, ICU, AssetRegistry
  <Project>-Windows.utoc / .ucas   ← IoStore (UE5, UE4.26+): ассеты (.uasset) — виджеты, таблицы строк
  global.utoc / .ucas              ← скриптовые объекты движка

Внутри PAK (виртуальные пути, mount point обычно ../../../):
  <Project>/Content/Localization/
    <Target>/                      ← «таргет» локализации: Game, а также плагины/модули
      <Target>.locmeta             ← метаданные: родной язык, список CompiledCultures
      <Target>.manifest / .archive ← (часто вырезаны из shipping-сборки, для игры не нужны)
      en/<Target>.locres           ← таблица текста английской культуры
      fr/<Target>.locres
      …
  Engine/Content/Localization/Engine/<culture>/Engine.locres   ← строки самого движка
```

Таргетов может быть несколько: основной `Game`, а также отдельные для настроек, плагинов, онлайн-модулей. **Каждый таргет переводится и собирается отдельно**; таргет без `ru` откатывается на язык по умолчанию.

## Формат `.locres` (версия 3, UE 4.24+)

- Заголовок: magic-GUID, версия.
- Таблица уникальных строк (UTF-16), счётчики ссылок.
- Namespaces → ключи → (хеш исходной строки, индекс строки).
- **Namespace** — для текста из StringTable равен имени таблицы (`ST_Common_Menu`); для текста из Blueprint/данных — пустая строка, ключ — GUID.
- **source_hash** = CRC32 исходного (английского) текста, посчитанный по UTF-32LE (`FCrc::StrCrc32`). Если в новом `.locres` хеш не совпадает с исходником игры, перевод игнорируется → **сохраняйте хеши из оригинального `en/<Target>.locres`**.

`.locmeta` — маленький бинарный файл: версия, NativeCulture, NativeLocRes, CompiledCultures. Новую культуру нужно добавить в CompiledCultures, чтобы язык появился в списке настроек.

## Как подложить перевод: mod-PAK

```
<Project>/Content/Paks/
  z_MyGame-RU_P.pak        ← только новые/изменённые файлы с теми же виртуальными путями
  z_MyGame-RU_P.utoc       ← (только если у игры есть IoStore) пустой компаньон
  z_MyGame-RU_P.ucas
```

- **Суффикс `_P`** повышает приоритет монтирования (+100 на каждый уровень `_N_P`), поэтому файлы мода перекрывают оригинальные с тем же путём. Префикс `z_` — просто сортировка.
- **Mount point** должен совпадать с оригиналом (обычно `../../../`), иначе виртуальные пути не сойдутся.
- **IoStore-игры:** если у оригинала есть `.utoc/.ucas`, то в типичной конфигурации PAK без парного `.utoc` **открывается, но отвергается** (`utoc not found`, исход M1). Решение — пустой IoStore-контейнер с тем же именем (например, `retoc to-zen` из пустого каталога).
- **Версия PAK** — как у оригинала (UE 5.x обычно V11). Сжатие и шифрование для мода не нужны, если игра их не требует.

Минимальный мод для нового языка:

```
<Project>/Content/Localization/Game/Game.locmeta        ← оригинал + "ru" в CompiledCultures
<Project>/Content/Localization/Game/ru/Game.locres      ← копия en/Game.locres с переведёнными строками
```

Тот же приём повторить для каждого таргета (`Settings`, `Lyra`, … — зависит от игры).

## Выбор языка

- В настройках игры (если игра строит список из CompiledCultures — новый язык появится сам).
- Параметр запуска `-culture=ru`.
- Конфиг пользователя: `Saved/Config/Windows/GameUserSettings.ini` → `[Internationalization] Culture=ru` (игра обычно пишет его сама после выбора в меню).

## StringTables

Таблицы строк (`/Game/Localization/StringTables/ST_*.uasset`) хранят **только исходный (английский) текст**; переводы на другие языки всё равно берутся из `.locres` с namespace = имя таблицы. Править `.uasset` для перевода не нужно.

## Шрифты

Шрифт в UE — composite font: основной typeface + fallback + sub-typefaces по диапазонам/культурам. Если в декоративном шрифте нет кириллицы, движок берёт глифы из fallback (часто Noto Sans) — квадратов нет, но начертание отличается. Проверяйте покрытие cmap шрифтов (`.ufont` = TTF/OTF внутри) **до** того, как браться за замену шрифтов.

## Подводные камни

| Симптом | Причина |
|---|---|
| Игра не видит мод совсем | неверное имя (`_P`), не тот каталог, игра запущена из другой копии |
| Мод открыт, но не работает (UE5) | нет пустого `.utoc/.ucas` |
| Языка нет в списке | `ru` не добавлен в `.locmeta` нужного таргета |
| Часть интерфейса по-английски | не переведены другие таргеты (Settings/плагины/Engine) или строка зашита в код |
| Перевод одной строки «переехал» на другие места | одна и та же строка разделяется несколькими ключами — переводите по ключу, а не по тексту |
| После обновления игры часть строк снова английская | изменился исходный текст → изменился source_hash; пересоберите из нового `en/*.locres` |
